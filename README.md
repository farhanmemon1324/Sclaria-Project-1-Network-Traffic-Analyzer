# Network Traffic Analyzer

**Sclaria Cybersecurity Internship – Project 1**

## Project Overview
This project focuses on capturing, monitoring, and analyzing network traffic using Wireshark.

## Tools and Environment
- Wireshark 4.6.7
- Windows 11
- Ethernet Network Interface

## Project Activities
- Live network packet capture
- Packet and protocol analysis
- Protocol Hierarchy analysis
- Network Conversations analysis
- TCP retransmission analysis
- TCP reset and initial SYN analysis

## Project Findings
- TCP retransmission-related packets: 35
- TCP reset packets: 15
- Initial TCP SYN count: Requires verification (the screenshot displays 166, while an earlier recorded result was 335).
